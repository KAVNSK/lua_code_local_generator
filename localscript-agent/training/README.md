# Опциональное дообучение (QLoRA)

Для обучения берите только проверенный ground truth:
- агентские/PDF эталоны;
- детерминированные шаблоны из `data/synthetic/`.

Ответы локальной `Ollama` нельзя использовать как "учителя" для разметки.

## Рекомендуемый процесс

1. Соберите один JSONL из `data/synthetic/seed_agent_examples.jsonl` и `generated.jsonl`.
2. Поднимите отдельное conda-окружение и установите `transformers`, `peft`, `trl` (или `unsloth`, если GPU совместим).
3. Обучите QLoRA на той же архитектуре, которая используется в `Ollama`.
4. Сделайте merge адаптера, экспортируйте в `GGUF`, затем создайте локальный тег через `ollama create`.
5. Прогоните `scripts/eval_public.py`; если результат хуже prompt-only baseline, вернитесь к официальной модели через `ollama pull`.

Если у вас `8 GB VRAM`, не запускайте одновременно тяжелое обучение и полный `Ollama` без плана по памяти.
