# Архив старого README

Этот файл создан перед обновлением основной документации.

Предыдущая версия README фокусировалась на:
- tim-style stateless API (`/generate`, `/refine`, `/debug`, `/health`);
- repair loop и расширенных полях ответа (`attempts`, `degraded`, `stop_reason`);
- демонстрационных клиентах CLI/Streamlit;
- тестах и скриптах оценки на публичной выборке.

Новая версия `README.md` сохраняет техническую суть и оформлена в более структурированном формате для инженерной эксплуатации и сравнения с вариантом `lua_manual`.
